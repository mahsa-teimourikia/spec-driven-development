# Trusted harness boundary

The teaching scanner runs outside the candidate's authority. It checks the actual Git base and head, reads source and dependency files from committed Git objects, records coverage and blind spots, signs the resulting observation, and passes that observation to the control plane.

The candidate may propose an ADR or request an exception. It cannot change the active policy revision, register its own exception authority, sign scanner evidence, invent compensating-control receipts, or authorize deployment. Exception approval, compensating-control observation, repository observation, and runtime network enforcement use distinct training trust anchors. The keys in this course are deterministic training fixtures only.
