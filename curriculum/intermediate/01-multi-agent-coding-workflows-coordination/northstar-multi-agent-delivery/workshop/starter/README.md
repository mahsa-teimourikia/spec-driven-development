# Starter workspace — coordinate AI-2219

Complete the three JSON artifacts before opening the `reference/` directory.

1. In `workflow.json`, justify multiple agents against a single-agent baseline, source finite coordination budgets, preserve the six-unit dependency graph, name contract consumers and integration inputs, and define exclusive writable paths, pinned context, review queues, verification independence, and bounded integration authority. Keep `PLANNED` and `READY` units unassigned; model identity, temporary permission, lease, and lock binding only at successful pull dispatch.
2. In `handoff.json`, publish exact outputs, contract revisions, evidence, discoveries, unresolved items, and the repository revision consumed by downstream work.
3. In `recovery-record.json`, reconstruct observable partial state, validate current contracts and repository context, inspect rather than trust partial work, and choose an explicit recovery outcome.
4. From the repository root, run `python3 curriculum/intermediate/01-multi-agent-coding-workflows-coordination/lab.py` to study the validator and failure injections.
5. Compare your artifacts with `../../reference/` only after you can explain every authority boundary and state transition.

The starter does not provision identities, permissions, branches, or agents. `TODO` values are prompts for the exercise, not executable defaults.
