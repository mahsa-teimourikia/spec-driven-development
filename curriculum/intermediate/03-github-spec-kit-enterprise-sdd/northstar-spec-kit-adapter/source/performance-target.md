# PERF-TARGET-003 — Classification proposal latency

Revision: `1-training`
Authority: Service Reliability

The approved target reference for the synthetic supported population is p95 proposal latency at or below 800 milliseconds, measured from normalized OCR availability to persisted non-authoritative proposal in the controlled performance environment.

Generated plans may preserve and measure this target; they may not replace it. Fixture results are not production SLO evidence.
