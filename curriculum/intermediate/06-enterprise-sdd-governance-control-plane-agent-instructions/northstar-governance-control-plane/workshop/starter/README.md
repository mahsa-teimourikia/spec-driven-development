# Starter task

Complete the three `TODO` fields in `governance-package.json` from trusted artifacts:

1. bind the package to the authoritative base revision;
2. preserve the governing human-review obligation; and
3. bind the package to the generated instruction manifest.

Do not edit policy, claim an exception, or hand-author an adapter. Record where each value came from and why that source has authority. Then compare your result with `../../reference/governance-package.json` and run `../../lab.py` from the repository root.
