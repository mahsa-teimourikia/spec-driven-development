# Workshop starter

Complete the five `TODO` decisions in `modernization-package.json` before reading the reference package.

1. Bind discovery to an exact repository revision.
2. Classify each observed behavior as preserve, modify, retire, defect, or unknown.
3. Express the semantic delta without silently replacing deterministic risk scoring.
4. Map every impacted consumer and retain the protected invariant suite.
5. Design an expand/shadow/limited rollout with an exercised rollback path.

Run `lab.py` to inspect the reference failure experiments. Your package may use a different migration pattern if its compatibility, authority, evidence, and rollback boundaries are explicit.
