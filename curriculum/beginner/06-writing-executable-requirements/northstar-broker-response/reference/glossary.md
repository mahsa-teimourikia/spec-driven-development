# AI-2219 controlled vocabulary

| Term | Definition |
| --- | --- |
| ProposedUpdate | A non-authoritative proposal linking a candidate field/value to exact response evidence and current specification context. |
| verified value | A submission value whose verification state was established by the authoritative application, not asserted by model text. |
| conflict | A different proposed value targets an existing verified value, or one response supplies incompatible candidates without resolution. |
| normative elaboration | A table, state model, or contract that adds binding detail because a normative requirement explicitly references it. |
| normative example | An acceptance scenario that illustrates required behavior without overriding the general requirement. |
| informative | Explanatory material that creates no obligation. |
| implementation-ready | The owning capability has approved, source-backed behavior, resolved blockers, required boundaries, and an evidence plan with no normative contradiction. |
