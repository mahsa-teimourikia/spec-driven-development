# AI-2219 — Broker response processing

When brokers reply to requests for missing information, use AI to understand their response and
update the underwriting workflow.

The agent should figure out which questions were answered, extract the relevant information, and
update the submission. If something is unclear, it should ask the broker again.

We want this to be mostly automated so underwriters do not have to review every response.

Make sure we do not overwrite good data.

## Product note

Release 1 receives authenticated portal responses. Attachment extraction is not yet supported. The
ticket does not itself authorize automatic mutation, define supported fields, or decide which field
classes may bypass review.
