# Northstar Underwriter agent instructions

These instructions are part of a training fixture. They guide repository work but do not grant authority.

- Work only inside this repository fixture and only on a feature branch.
- Do not call external model APIs, deploy infrastructure, or use real customer data.
- Read `ticket/`, applicable `context/`, and `docs/decisions/` before proposing code.
- Treat requirement ownership, applicability, policy exceptions, and deployment approval as human decisions.
- Use the approved model-gateway abstraction and preserve the public response contract.
- Keep generated evidence free of secrets and private model reasoning.
- Stop on conflicting mandatory requirements, uncertain applicability, missing provenance, or permission outside the declared boundary.
