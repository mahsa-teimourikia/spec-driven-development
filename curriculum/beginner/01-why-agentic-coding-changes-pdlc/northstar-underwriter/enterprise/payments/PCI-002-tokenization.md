# PCI-002 — Payment-card tokenization

Owner: Payment Security
Version: 6.0
Effective: 2025-01-01

Payment-card data SHALL be tokenized before storage.

This active mandatory policy is deliberately irrelevant to JIRA-4821. A professional context-discovery process records it as not applicable instead of loading it into the implementation context or pretending it does not exist. Machine-readable control: `C-90`.
