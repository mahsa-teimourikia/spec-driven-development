# Starter workspace

Complete both starter artifacts before viewing the reference package.

- In `ambiguity-register.md`, classify each gap as an unknown, ambiguity, conflict, design question,
  or policy decision. Assign an owner and name only the capability it blocks.
- In `requirements-package.json`, replace each `TODO` while preserving stable IDs. Keep priority
  separate from normative strength, and keep auto-send disabled while `OQ-017` is open.
- Run `lab.py --package <this requirements-package.json>` and use its findings as review evidence.

The lab is a quality aid, not an approval authority. A clean result cannot prove that discovery is
complete or that the listed people and sources are authentic.
