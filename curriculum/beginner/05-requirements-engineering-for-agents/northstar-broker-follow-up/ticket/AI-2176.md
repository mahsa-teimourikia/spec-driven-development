# AI-2176 — Broker Follow-up Assistant

Underwriters lose time checking submissions and writing follow-up emails. Build an AI feature that
inspects every submission, finds missing information, and prepares an accurate, professional broker
message quickly. Do not bother brokers with unnecessary questions.

For simple cases, automatically send the message so brokers get a quick response. Reuse the existing
underwriting agent if possible.

## Product intent

- reduce repetitive review and drafting work;
- shorten time until brokers know what is missing; and
- preserve a professional broker experience.

## Missing decisions

The ticket does not define “missing,” “accurate,” “professional,” “quick,” or “simple.” It does not
name supported products, authority for auto-send, version/freshness behavior, approval semantics,
failure outcomes, measurements, or the source that determines required submission information.
