# Enterprise Agent capstone

The capstone asks learners to design a real enterprise Agentic PDLC rather than finish a toy coding project.

The final evidence package will include a specification hierarchy, risk-tiered workflow, framework decision, agent authority model, human approval gates, policy-as-code controls, CI/CD enforcement, traceability, evaluation plan, drift response, exception path, and rollout metrics.

The capstone is planned; its prerequisites and acceptance criteria are defined in the [course plan](../../COURSE_PLAN.md).
